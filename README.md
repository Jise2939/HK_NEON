This is the README file for the HK_NEON project.  
It is a course project of MEJO 187 at the UNC Hussman School of Journalism and Media.

## Project Structure

- `css/`: CSS files for different pages.
- `img/`: Images used in the project.
- `video/`: Video files used in the project.
- `js/`: JavaScript files for the project (demonstration only).
- `index.html`: The main HTML file for the project.
- `README.md`: This file, providing an overview of the project.

## Disclaimer

The HK_NEON project is intended for educational purposes only. Any content, images, or videos used in the project are for demonstration purposes and may not reflect real-world scenarios.
